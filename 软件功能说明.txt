  一、软件概述
════════════════════════════════════════════════════════════════════════════════

DataProcessor Pro 是一款基于 PyQt6 开发的桌面数据分析软件，专注于光纤传感器
（FBG）数据处理、物理量计算、统计分析和 AI 辅助报告生成。

技术栈：PyQt6 + Pandas + NumPy + SciPy + Matplotlib + python-docx + OpenAI SDK

主要模块文件：
  main.py                  - 主程序（UI + 业务逻辑）
  py/online_llm_thread.py  - 在线大模型流式推理线程
  py/ollama_client.py      - 本地 Ollama 模型管理客户端
  py/local_llm_manager.py  - 本地 LLM 模型管理器
  py/llama_generate_thread.py - 本地 LLM 推理线程
  py/analyzer.py           - 数据分析模块
  py/cleaner.py            - 数据清洗模块
  py/formula.py            - 公式计算模块
  py/processor.py          - 数据处理模块
  py/report.py             - 报告生成模块
  py/template.py           - 数据模板模块

配置文件：
  ai_models_config.json    - 模型配置（API Key等敏感信息）
  ai_presets.json          - 预设模型模板

════════════════════════════════════════════════════════════════════════════════
  四、标签页2 — 数据清洗
════════════════════════════════════════════════════════════════════════════════

功能：
  - 异常值检测与标记
  - 缺失值填充
  - 支持多种清洗规则组合

清洗规则：

  规则1：相邻数据差值检测
    - 原理：当前值与前一值的差的绝对值 > 阈值 → 标记为异常
    - 可配置：差值阈值（默认 1.0）

  规则2：缺失值检测
    - 检测 NaN / 空值
    - 可配置：启用/禁用

  规则3：范围检测（代码支持，UI可扩展）
    - 检测超出 [min, max] 范围的值

  规则4：负值检测
    - 标记所有负数

  规则5：零值检测
    - 标记所有零值

填充方式（异常/缺失值替换策略）：
  | 方式      | 说明                   |
  |----------|----------------------|
  | linear   | 线性插值（默认）        |
  | mean     | 均值填充               |
  | forward  | 前向填充（用前一个有效值） |
  | backward | 后向填充（用后一个有效值） |
  | custom   | 自定义固定值填充        |

实现（main.py）：
  - CleaningRule 类（第72行）：清洗规则数据结构
  - detect_anomalies() 函数（第84行）：异常值检测引擎
  - fill_missing() 函数（第125行）：缺失值填充引擎
  - clean_data() 函数（第154行）：完整清洗流水线

  五、标签页3 — 光纤公式配置
════════════════════════════════════════════════════════════════════════════════

功能：
  - 定义 FBG（光纤布拉格光栅）参数
  - 定义传感器及物理量计算公式
  - 计算物理量（应变、温度、位移、倾角、压力）
  - 预览和导出传感器数据

5.1 FBG 定义
  - 属性：ID、波长列名、波长下限、波长上限
  - 操作：添加 / 编辑 / 删除
  - 表格管理 + 对话框编辑

5.2 传感器定义
  - 属性：ID、类型、计算公式、系数常量、启用状态
  - 操作：添加 / 编辑 / 删除 / 复制

  支持的传感器类型：
  | 类型         | 单位  | 说明          |
  |-------------|------|-------------|
  | strain      | με   | 应变（支持温度补偿）|
  | temperature | °C   | 温度          |
  | displacement| mm   | 位移          |
  | inclination | °    | 倾角          |
  | pressure    | MPa  | 压力          |

5.3 物理量计算公式系统
  - 公式示例： "W1 * k1"、"W1 * k1 - W2 * k2"（温补应变）
  - 基于参考行差值计算：(当前波长 - 初始波长) × 系数
  - 支持多 FBG 组合运算
  - 参考行可配置（第 N 行的值作为基准）

5.4 计算与保存
  - "计算所有传感器"按钮 → 将公式应用于每行数据
  - 结果预览表格（最大高度200px）
  - 导出格式：CSV / TXT / XLSX

实现（main.py）：
  - FBG 类（第163行）：光纤光栅定义
  - Sensor 类（第180行）：传感器定义及类型参数
  - SensorSystem 类（第225行）：传感器系统管理，包含核心计算公式引擎
  - FBGEditDialog / SensorEditDialog：编辑对话框

════════════════════════════════════════════════════════════════════════════════
  六、标签页4 — 数据分析
════════════════════════════════════════════════════════════════════════════════

6.1 数据源选择
  - 可选择"原始数据"或"物理量"（传感器计算结果）
  - 物理量模式下显示可用传感器列表
  - 支持手动刷新传感器列表

6.2 数据范围
  - 序号范围：从第 N 行到第 M 行
  - 时间范围：按时间戳筛选
  - "应用范围"按钮 → 重新绘制图表

6.3 图表显示
  - Matplotlib 嵌入式图表（FigureCanvasQTAgg）
  - Matplotlib 内置工具栏（框选放大、拖动平移、缩放、保存等）
  - 曲线随数据源和范围动态更新

6.4 统计信息
  - 按曲线展示统计指标：
    · 最大值、最小值、平均值、标准差
    · 峰峰值、有效值（RMS）
    · 偏度（Skewness）、峰度（Kurtosis）
  - 通过下拉框切换要查看的曲线

6.5 曲线对比
  - 选择两条曲线进行统计对比
  - 输出对比结果文本

6.6 信号处理（内置函数，第348-385行）
  - 时域分析：均值、最大值、最小值、RMS、标准差
  - 频域分析（FFT）：频谱计算、主频提取
  - 数字滤波：低通 / 高通 / 带通（Butterworth 4阶滤波器）
  - 滤波参数可配置：截止频率、采样率

6.7 图表导出
  - 支持 PNG 格式导出
  - 自定义 DPI（默认150）

实现：
  - time_domain_analysis()（第348行）、frequency_domain_analysis()（第360行）
  - apply_filter()（第374行）
  - run_analysis()（第3299行）、compare_curves()（第3698行）

════════════════════════════════════════════════════════════════════════════════
  十四、技术架构特点
════════════════════════════════════════════════════════════════════════════════

  1. 多线程处理
     - AI 推理使用 QThread 不阻塞 UI
     - PyQt 信号槽机制进行线程间通信
     - 测试连接使用 daemon 线程 + 信号发射器

  2. 流式输出
     - AI 回答实时逐 token 显示
     - 智能缓冲（3字符或标点触发刷新）

  3. 图表交互
     - 完整的 Matplotlib 工具栏（缩放、平移、保存）
     - 支持框选放大和右键菜单

  4. 数据安全
     - API Key 使用密码输入框（EchoMode.Password）
     - 配置文件本地 JSON 存储
     - 预设不保存 API Key

  5. 可扩展性
     - 数据模板系统（支持添加新格式）
     - 传感器类型系统（TYPE_PARAMS 字典）
     - 清洗规则可扩展
     - API 平台预设可自定义
