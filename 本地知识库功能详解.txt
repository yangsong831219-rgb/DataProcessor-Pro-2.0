================================================================================
  DataProcessor Pro 2.0 — 本地知识库系统 功能详解
  生成日期: 2026-05-28
================================================================================

【系统架构】
  知识库系统基于纯本地文件系统实现，不依赖任何外部数据库或云服务。
  存储位置: <软件目录>/wiki_vault/
  核心文件: py/wiki_system.py (后端) + main.py create_wiki_page() (UI)
  辅助模块: py/web_clipper.py (网络剪藏)

  目录结构:
    wiki_vault/
    ├── pages/              # Markdown 页面 + 附件 (图片/文件)
    │   ├── xxx.md
    │   └── assets/         # 本地化图片等资源
    └── wiki_map.json       # 索引数据库 (页面名 → 路径 + 标签 + 摘要)

================================================================================
  一、后端 API — WikiFileSystem (py/wiki_system.py)
================================================================================

1. read_wiki_map() → JSON 字符串
   - 读取 wiki_map.json 完整索引表
   - 包含版本号、最后更新日期、所有页面元数据

2. update_wiki_map(page_name, path, tags, summary)
   - 向索引表注册或更新一个页面
   - params: 页面名称、相对路径、标签列表、页面摘要

3. read_wiki_page(page_name) → Markdown 字符串
   - 根据名称读取页面完整内容 (UTF-8)
   - 先从索引表查路径，未命中则回退到 pages/{name}.md

4. write_wiki_page(page_name, content, author)
   - 新建或更新页面 (Upsert 语义)
   - 更新已有页面时采用追加模式：
     已有内容 + 分隔线 + 更新时的新内容 (保留历史版本)
   - 自动创建不存在的子目录

5. delete_wiki_page(page_name)
   - 从文件系统和索引表中删除指定页面
   - 仅删除已索引的页面 (防止误删)

6. upload_file_to_wiki(source_path, target_name)
   - 将任意文件 (PDF/图片/Word等) 复制到 pages/ 目录
   - 文件名冲突时自动添加 _1, _2 后缀
   - 自动注册到索引表

7. delete_file_from_wiki(page_name)
   - 从文件系统和索引表删除文件
   - 支持精确匹配和模糊匹配 (自动补全 .md 扩展名)

8. read_wiki_file_binary(page_name) → (路径, bytes)
   - 二进制模式读取 (用于图片、PDF 等非文本文件)
   - 返回文件完整路径和二进制内容元组

9. sync_missing_pages() → 新注册数量
   - 扫描 pages/ 目录，自动发现并注册未索引的 .md 文件
   - 页面名称 = 文件名去扩展名
   - 保障手动放入的文件能被系统识别

10. list_pages() → 格式化字符串
    - 列出所有已索引页面
    - 自动调用 sync_missing_pages() 同步
    - 输出 # 标题 + 路径 + 标签 + 摘要

11. search_pages(keyword) → 搜索结果
    - 关键词搜索：先匹配页面名，再全文搜索内容
    - 大小写不敏感
    - 自动同步未索引文件后再搜索

================================================================================
  二、UI 功能 — 知识库管理页面 (main.py)
================================================================================

【页面布局 — 三区域结构】
  顶部工具栏  →  [新建] [删除] [上传文件] [说明] [保存页面]
  中部导航条  →  [搜索关键词输入框] + [页面标题输入框]
  下部工作区  →  左侧页面列表 | 右侧 Markdown 编辑器 (可拖拽分割)

【核心操作】

1. 浏览与查看
   - 左侧页面列表实时显示所有已保存页面
   - 点击任意页面 → 标题框同步更新 + 编辑区加载 Markdown 原文
   - 支持可拖拽分割器调整左右面板宽度

2. 新建页面 (+ 新建)
   - 清空标题和内容区
   - 输入标题 → 编写 Markdown 内容 → 点击"保存页面"
   - 支持标题、列表、代码块、表格、粗体、斜体等完整 Markdown 语法

3. 编辑页面
   - 点击左侧列表项加载页面
   - 直接在编辑器修改内容
   - 点击"保存页面"保存 (追加模式：旧内容 + 分隔线 + 新内容)

4. 删除页面
   - 先在左侧列表选中页面，再点击"删除"按钮
   - 弹出确认对话框防止误操作
   - 同时删除文件和索引条目

5. 搜索功能
   - 在搜索框输入关键词 → 实时在页面名称和正文中搜索
   - 搜索结果列表显示匹配项
   - 点击搜索结果 → 加载对应页面

6. 上传文件
   - 点击"上传文件" → 文件选择对话框
   - 支持任意文件类型 (PDF、Word、图片、文本等)
   - 自动复制到 wiki_vault/pages/ 并注册索引

7. 沉浸式阅读模式
   - 全屏渲染 Markdown 为美观的阅读视图
   - 支持图片渲染、表格格式化、代码语法高亮
   - 右上角"返回编辑"按钮退出全屏

8. 页面标题自动同步
   - 编辑区内容变化时，右侧标题编辑框同步更新
   - 支持中文、英文、特殊字符组合的标题

================================================================================
  三、网络剪藏 — WebClipper (py/web_clipper.py)
================================================================================

【功能定位】
  将外部网页内容一键抓取并保存到本地知识库，实现"阅读 → 剪藏 → 知识沉淀"
  的闭环工作流。

【支持平台】
  - 微信公众号文章 (mp.weixin.qq.com)
  - 知乎文章 (zhihu.com)
  - 学术期刊 (ScienceDirect / Springer / IEEE 等摘要页)
  - Bilibili 视频详情页 (bilibili.com)
  - YouTube 视频详情页 (youtube.com)

【核心能力】

1. fetch_article(url, cookies) → (title, markdown_content)
   - 多平台智能识别：自动检测 URL 来源并采用对应解析策略
   - 微信公众号：支持 cookie 传入以获取完整正文
   - 通用网站：使用 trafilatura 智能提取正文 (去广告/导航/侧栏)

2. download_and_replace_images(md_content, base_url, save_dir) → 更新后的 MD
   - 扫描 Markdown 中的图片 URL
   - 下载所有外链图片到 wiki_vault/pages/assets/ 本地化为相对路径
   - 使用 MD5 哈希 + 时间戳生成唯一文件名
   - 自动识别真实图片扩展名 (PNG/JPEG/GIF/WebP)

3. download_video(url, output_dir) → 本地视频文件路径
   - 使用 yt-dlp 下载 Bilibili / YouTube 视频
   - 支持自动选择最佳质量和格式
   - 返回下载后的本地文件路径

4. save_to_wiki(url, title, md_content) → 保存结果
   - 将剪藏的 Markdown 内容保存为知识库页面
   - 自动添加元数据头 (来源 URL、抓取时间)
   - 自动注册到 wiki_map.json 索引

5. clip(url, download_images=True, cookies="") → (title, content)
   - 一键式高级 API：抓取 + 图片本地化 + 内容清洗
   - 返回 (标题, Markdown内容) 可直接 save_to_wiki 入库
   - 内置请求频率控制和 User-Agent 轮换

6. _clean_article_content(md_content) → 清洗后内容
   - 去除多余的空白行和广告残留
   - 规范化 Markdown 格式
   - 修复破碎的链接和图片引用

================================================================================
  四、AI 技能联动
================================================================================

知识库通过 py/multi_agent.py 和 py/agent_skill_hub.py 与 AI Agent 深度集成：

  Agent 可调用的知识库技能:
  - read_wiki_page:   读取指定知识库页面内容作为分析上下文
  - write_wiki_page:  将分析结果/经验总结写入知识库
  - search_wiki_pages: 搜索知识库中相关案例参考
  - list_wiki_pages:  列出所有可用知识页面
  - read_wiki_map:    读取完整索引表

  典型场景:
  - 传感器数据分析 → Agent 自动检索知识库中的历史案例 → 生成诊断报告
  - 数据异常解释 → Agent 搜索类似模式的经验记录 → 给出可能原因
  - 分析完成后 → Agent 将发现和新知识自动写入知识库沉淀

        "summary": "页面摘要描述"
      }
    }
  }

================================================================================
  六、性能特点
================================================================================

  - 纯文本存储，无数据库依赖，零配置启动
  - Markdown 格式，可用任何文本编辑器编辑和查看
  - 自动同步：手动放入 pages/ 的文件会被 sync_missing_pages() 自动发现
  - 追加式版本管理：更新页面时保留旧内容
  - 跨平台兼容：Windows / macOS / Linux 均可使用
  - 启动时自动同步未索引文件
