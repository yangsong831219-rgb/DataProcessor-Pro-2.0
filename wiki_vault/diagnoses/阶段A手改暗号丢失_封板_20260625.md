# 阶段A 手改暗号丢失封板 — 同会话编辑持久化 + 合并反转 + 公共函数抽离

**日期**: 2026-06-25
**状态**: ✅ 封板
**批次**: 阶段A 对话框暗号编辑持久化

## 根因

1. **`_on_apply` 只写对话框本地，不写回主页面** — `calibration_tab.py:1290-1355` 只操作 `self._annotation` / `self._annotation_dirty` / `self._groups`（对话框本地属性），不调用 `_write_state_to_main_page`，不写入 `tp._annotation_dict` / `tp._phase_a_state`
2. **`__init__` 合并"文件为底"反模式** — `calibration_tab.py:1057-1058,1077-1084` 与旧版 `restore()` 同构：`self._annotation = dict(file_annotation)` 以文件为底，dirty 空集时文件值覆盖手改值

两因叠加：用户点「应用暗号」→ 改的是本地副本 → 用 X/Esc 关闭 → 下次重开时 `tp._annotation_dict` 仍是旧值 → `__init__` 从旧值初始化 → 手改丢失。
