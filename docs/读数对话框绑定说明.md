## 1. self._readings 的活形状

### 1.1 定义

```python
# ui/calibration_tab.py:2914
self._readings = {}
```

初始化为空 dict，类型注解缺失（推断为 `dict[int, dict[int, dict[str, list[float]]]]`）。

### 1.2 真实嵌套结构

```
_readings: dict[int, dict[int, dict[str, list[float]]]]
  │          grating    cycle     direction
  │          (1或2)    (1..n)    ("load"|"unload")
  │
  └── 键为 int (grating index)，非 str
```

### 1.3 填充示例（用户录入完成后、对话框关闭瞬间）

`_extract_table_data()` 写入后的形状（双栅 + 3 循环 + 张拉退回模式）:

```python
# ui/calibration_tab.py:3352-3375 — 这是填充 _readings 的唯一写入口
{
    1: {  # G1
        1: {"load": [1540.123, 1540.234, 1540.345, ...]},   # C1 张拉, 11个值(对应11个位移等级)
        2: {"load": [1540.456, 1540.567, 1540.678, ...]},   # C2 张拉
        3: {"load": [1540.789, 1540.890, 1541.001, ...]},   # C3 张拉
    },
    2: {  # G2
        1: {"load": [1539.111, 1539.222, 1539.333, ...],
             "unload": [1539.099, 1539.210, 1539.321, ...]},  # C1 退回 (仅 tension_return 模式)
        2: {"load": [...], "unload": [...]},
        3: {"load": [...], "unload": [...]},
    },
}
```

**写回代码证据** (`ui/calibration_tab.py:3363`):

```python
readings.setdefault(gi + 1, {})[ci + 1] = {"load": load_vals}
```

`gi + 1` = 1, 2, ... (int 键)  
`ci + 1` = 1, 2, 3, ... (int 键，1-indexed)  
`{"load": load_vals}` 且可选 `{"load": load_vals, "unload": unload_vals}`（仅 `tension_return` 模式）。

每个 `load`/`unload` 值数组长度 = `len(self._levels)`（位移等级数，默认 11）。

### 2.1 入口

### 2.2 列头生成 (`_build_table_columns`)

```python
# ui/calibration_tab.py:3248-3269
def _build_table_columns(self):
    c = self._config
    is_return = c["mode"] == "tension_return"      # ★ mode 决定是否有"退回"列
    n_gratings = 1 if c["grating_kind"] == "single" else 2
    cols = ["位移(mm)", "理论应变(με)"]
    for ci in range(c["n_cycles"]):                # 循环外层
        for gi in range(n_gratings):               # 光栅内层
            cols.append(f"G{gi+1}_C{ci+1}_张拉(nm)")
        if is_return:
            for gi in range(n_gratings):
                cols.append(f"G{gi+1}_C{ci+1}_退回(nm)")
    return cols
```

列索引映射:
- `col=0`: 位移(mm)
- `col=1`: 理论应变(με)
- `col=2`: `G1_C1_张拉(nm)` (第一个波长数据列)
- ... (依次展开循环×光栅×方向)

**退回列是否出现完全由 `self._config["mode"]` 决定**。

### 2.3 波长读数填充 (`_populate_table`)

```python
# ui/calibration_tab.py:3271-3307
col_idx = 2
for ci in range(c["n_cycles"]):
    for gi in range(n_gratings):
        # ★ 从 _readings 取 load 方向的值
        load_vals = self._readings.get(gi + 1, {}).get(ci + 1, {}).get("load", [])
        for r in range(len(self._levels)):
            val = load_vals[r] if r < len(load_vals) else 0.0
            item = QTableWidgetItem(f"{val:.3f}" if isinstance(val, (int, float)) else "0.000")
            table.setItem(r + 1, col_idx, item)  # row+1 因为没有备注行
        col_idx += 1
    if is_return:
        for gi in range(n_gratings):
            unload_vals = self._readings.get(gi + 1, {}).get(ci + 1, {}).get("unload", [])
            for r in range(len(self._levels)):
                val = unload_vals[r] if r < len(unload_vals) else 0.0
                item = QTableWidgetItem(f"{val:.3f}" if isinstance(val, (int, float)) else "0.000")
                table.setItem(r + 1, col_idx, item)
            col_idx += 1
```

**读取路径**: `_readings[grating_int][cycle_int]["load"][row_index]`  
行索引与 `self._levels` 一一对应。若 `_readings` 为空 `{}`（加载项目后默认），则所有波长列填充 `0.000`。

## 3. 写回方向：用户输入某格波长值 → _readings 的哪个确切路径

### 3.1 写回触发

对话框关闭时 `dlg.finished` 信号统一触发 `_on_closed`，**不走按钮 click handler**:

```python
# ui/calibration_tab.py:3508-3514

    self._dialog_table = None
    self._annotation_combos = {}
dlg.finished.connect(_on_closed)
```

四条关闭路径（确定/取消/Esc/X/Alt+F4）全部覆盖。

### 3.2 逐格提取到 _readings

```python
# ui/calibration_tab.py:3316-3377
def _extract_table_data(self, table):
    readings: dict[int, dict] = {}
    col_idx = 2
    for ci in range(c["n_cycles"]):
        for gi in range(n_gratings):
            load_vals = []

                    load_vals.append(0.0)

            readings.setdefault(gi + 1, {})[ci + 1] = {"load": load_vals}
            col_idx += 1
        if is_return:
            for gi in range(n_gratings):
                unload_vals = [...]
                # ★ 写回路径: _readings[gi+1][ci+1]["unload"] = [...]
                readings[gi + 1][ci + 1]["unload"] = unload_vals
                col_idx += 1
    return levels, readings, grating_map
```

**确切路径**:
- 用户在第 `r` 行 (数据行) 编辑 `G1_C2_张拉` 列 → `_readings[1][2]["load"][r-1]` = 用户输入值
- 用户在第 `r` 行编辑 `G2_C1_退回` 列 → `_readings[2][1]["unload"][r-1]` = 用户输入值

### 3.3 写入是整体覆盖，非增量

```python
# ui/calibration_tab.py:3510
self._levels, self._readings, self._grating_map = self._extract_table_data(table)
```

每次对话框关闭都**完整重写**这三个变量，从表格逐格扫描重建，不是增量 patch。

## 4. _levels 与 _readings 的关系

### 4.1 两列分工

| 列 | 列名 | 数据源 | 编辑性 |
|----|------|--------|--------|
| 0 | 位移(mm) | `self._levels` | 可编辑 |
| 1 | 理论应变(με) | 自动计算 `disp / gauge × 1e6` | **只读** |
| 2+ | G*_C*_张拉/退回(nm) | `self._readings` | 可编辑 |

**证据 1 — 位移列填充** (`ui/calibration_tab.py:3283-3291`):

```python
for r, disp in enumerate(self._levels):
    data_row = r + 1  # 偏移: row 0 = 备注行
    table.setItem(data_row, 0, QTableWidgetItem(f"{disp:.3f}"))
    # 应变自动计算
    eps = disp / gauge * 1e6 if gauge > 0 else 0.0
    strain_item = QTableWidgetItem(f"{eps:.2f}")
    strain_item.setFlags(strain_item.flags() & ~Qt.ItemFlag.ItemIsEditable)
    table.setItem(data_row, 1, strain_item)
```

**证据 2 — 波长列填充** (`ui/calibration_tab.py:3293-3307`): 见第 2.3 节。

### 4.2 拟合 Ke 时喂入哪个

**喂入的是 `self._readings`（原始波长数据），不是 `_levels`。**

```python
# ui/calibration_tab.py:3579-3593
def _run_analysis(self):
    _, readings = self._get_table_data()      # ★ 返回 self._readings
    gauge = self._config["gauge_length_mm"]

    config = StrainCalibrationConfig(
        gauge_length_mm=gauge, mode=self._config["mode"],
        n_cycles=self._config["n_cycles"],
        grating_kind=self._config["grating_kind"],
        anchored_grating=self._config["anchored_grating"],
        levels=self._levels,                   # ★ _levels 作为 config 的 levels 字段
    )

    self._worker = StrainCalibrationWorker(config, readings)  # ← readings 直接传给 worker
```


```python
# ui/calibration_tab.py:844-856
class StrainCalibrationWorker(QThread):
    def __init__(self, config, readings):
        self.config = config; self.readings = readings
    def run(self):
        result = calibrate_strain(self.config, self.readings)  # ★ readings 直达拟合引擎
```

```python
# py/calibration/strain_calibration.py:102-122
def calibrate_strain(config, readings):
    eps_theory = compute_theoretical_strain(config.levels, config.gauge_length_mm)
    for gi in grating_indices:
        gr = _calibrate_one(gi, config, readings.get(gi, {}), eps_theory)
        # ★ readings.get(gi, {}) → 取出该光栅的 {cycle: {load: [...]}}
```

**两样都喂**，但用途不同:
- `config.levels` → 计算 `eps_theory`（理论应变值）
- `readings` → 取实际波长读数做 linear regression `np.polyfit(eps_theory, dl, 1)` → 得出 Ke

## 5. 生命周期

### 5.1 正常录入流程（不涉及 save/load）

```
页面初始化
  self._readings = {}               # ui/calibration_tab.py:2914
  ↓
用户第一次点「读数录入…」
  _open_readings()                  # ui/calibration_tab.py:3444

    → _StrainPasteTable(rows+1, cols)  # 新建独立表格

    → 仅位移→应变自动计算，不写 _readings
  ↓

  dlg.finished → _on_closed()       # ui/calibration_tab.py:3509
    → _extract_table_data(table)    # 从表格逐格扫描重建
    → self._readings = 新建的完整 dict  # ★ 覆盖写回

    → self._grating_map = 暗号映射   # ★ 也覆盖
  ↓
用户点「提交并分析」
  _run_analysis()                   # ui/calibration_tab.py:3579
    → _get_table_data()             # 返回 self._levels, self._readings
    → StrainCalibrationWorker(config, self._readings)
    → calibrate_strain(config, self._readings)
    → worker.finished → _on_strain_result()
    → self._ke_results = 拟合结果
    → self._working_result = _build_strain_subconfig()
```

### 5.2 关键观察

- **_readings 在正常流程中从不被置空**。从用户最后一次关闭对话框起，到拟合完成，它一直保持规范存储形状。
- **唯一置空发生在加载项目时**：

```python
# ui/calibration_tab.py:3849
self._readings = {}  # readings 存的是 raw dict 格式，这里不清零等 _open_readings 载入
```

这是 `_load_sensor_to_workspace()` 中，`_strain_configs` 的 `readings` 字段仅含 `[{disp_mm, eps_theory}]`（无原始波长），无法从中重建 `self._readings`，因此强制置空。

- **_open_readings 每次新建独立 QTableWidget**（`ui/calibration_tab.py:3466`），表格是 transient 对象，不与页面持久绑定。
- **`_dialog_table` 在对话框关闭时被设为 None**（`ui/calibration_tab.py:3511`），确保垃圾回收。

## 6. mode 与列结构

### 6.1 列数决定公式

```python
# ui/calibration_tab.py:3248-3269
def _build_table_columns(self):
    c = self._config
    is_return = c["mode"] == "tension_return"      # ★ 唯一判断
    n_gratings = 1 if c["grating_kind"] == "single" else 2
    cols = ["位移(mm)", "理论应变(με)"]
    for ci in range(c["n_cycles"]):
        for gi in range(n_gratings):
            cols.append(f"G{gi+1}_C{ci+1}_张拉(nm)")
        if is_return:
            for gi in range(n_gratings):
                cols.append(f"G{gi+1}_C{ci+1}_退回(nm)")
    return cols
```

列数: `2 + n_cycles × n_gratings × (2 if tension_return else 1)`

| mode | 单栅+3循环 | 双栅+3循环 |
|------|-----------|-----------|
| `tension_only` | 2+3×1×1=5 列 | 2+3×2×1=8 列 |
| `tension_return` | 2+3×1×2=8 列 | 2+3×2×2=14 列 |

### 6.2 加载时的 mode 丢失

```python

self._config.update({
    ...
    "mode": "tension_only",  # ★ 硬编码，原 mode 丢失
```

## 7. 暗号下拉来源

### 7.1 下拉数据源函数

```python
# ui/calibration_tab.py:3216-3233
def _get_temp_annotations(self) -> list[str]:
    """获取温度标定页已识别的全部暗号，供备注行下拉使用。"""
    tp = self._get_temp_page()
    if tp is None:
        return []
    groups = getattr(tp, '_annotation_groups', None) or {}
    codes: list[str] = []
    for _pfx, gratings in groups.items():
        for g in gratings:
            name = str(g.get("name", "")).strip()
            if is_valid_annotation(name):
                codes.append(name)
    return sorted(set(codes))
```

**依赖对象**: `tp._annotation_groups` — 这是温度标定页 `TemperatureCalibrationPage` 的实例属性，在 Phase A 暗号补填完成后由 `_group_annotations_by_prefix()` 填充。

### 7.5 从 grating_map 推断传感器名

```python
# ui/calibration_tab.py:3134-3156
def _parse_sensor_from_grating_map(self) -> str:
    """从 grating_map 的暗号值推断传感器名前缀。
    例: {"G1": "A1-W1", "G2": "A1-W2"} → "A1"
    """
    sources = self._get_grating_sources()
    prefixes: set[str] = set()
    for ann in sources.values():
        ann = ann.strip()
        if '-' in ann:
            prefixes.add(ann.rsplit('-', 1)[0])    # "A1-W1" → "A1"
        elif '_' in ann:
            prefixes.add(ann.rsplit('_', 1)[0])
        else:
            prefixes.add(ann)
    if len(prefixes) == 1:
        return next(iter(prefixes))
    return ""  # 多前缀不一致 → 调用方提示
```

**暗号格式要求**: `{传感器前缀}-{光栅编号}`，如 `A1-W1`、`B1-W2`。
