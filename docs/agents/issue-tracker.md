# Issue tracker: GitHub

本仓库的任务、缺陷和 PRD 使用 GitHub Issues 管理。远端仓库为
`yangsong831219-rgb/DataProcessor-Pro-2.0`。

## 操作约定

- 创建、读取、评论、标记或关闭 Issue 时，优先使用已连接的 GitHub 插件。
- GitHub 插件不可用时，使用 `gh` CLI，并让它从当前仓库的 Git 远端自动识别仓库。
- 发布 PRD 到任务跟踪器时，创建一个 GitHub Issue。
- 获取相关任务时，读取 Issue 正文、评论和标签。

## 当前环境说明

截至 2026-07-15，GitHub 插件加载未完成，当前机器也未安装 `gh` CLI。
在其中一个入口可用前，可以继续本地代码分析，但不得声称已经读取或修改远端 Issue。
