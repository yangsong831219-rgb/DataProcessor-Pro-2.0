# Triage labels

工程技能使用以下五个规范角色。右列是 GitHub Issues 中应使用的实际标签。

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不计划处理 |

工程技能提到角色名称时，必须使用表中对应的 GitHub 标签，不得自行创建同义标签。
