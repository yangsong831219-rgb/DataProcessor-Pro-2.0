# Domain docs

本仓库采用单上下文领域文档布局。

## 分析前读取

- 根目录 `CONTEXT.md`（存在时）。
- `docs/adr/` 中与当前工作区域有关的架构决策记录。
- 如果根目录出现 `CONTEXT-MAP.md`，按其映射读取与当前任务相关的上下文文件。

这些文件尚不存在时应继续工作，不要把缺少预建文档当作阻塞条件。领域术语或架构决策在后续讨论中形成后，再按需创建。

## 术语和决策规则

- 问题标题、重构建议、诊断假设和测试名称应使用 `CONTEXT.md` 定义的领域词汇。
- 不得随意用近义词替换已有领域术语。
- 若建议与现有 ADR 冲突，必须明确指出冲突的 ADR 及重新讨论的理由，不能静默覆盖。
