## 1. 关联资料列表 (多选) — `_proj_file_list`

### 1.1 添加

`report_workbench.py:381-389`:

```python
def _on_add_project_file(self) -> None:
    paths, _ = QFileDialog.getOpenFileNames(...)
    for path in paths:
        item = QListWidgetItem(path)
        item.setToolTip(path)
        self._proj_file_list.addItem(item)
```

### 1.2 是否可删除

**没有。** `_proj_file_list` 是标准 `QListWidget`，已设 `MultiSelection` (`line 225-227`)，支持 Keyboard Delete 键（Qt 默认行为: `QAbstractItemView` 按 Delete 键不自动删 items——需手动接 `keyPressEvent` 或添按钮）。当前没有任何 handler 响应选中项删除。

### 1.3 怎么取选中项、怎么删

Qt 标准 API:

```python
# 取选中项
selected = self._proj_file_list.selectedItems()
rows = [self._proj_file_list.row(item) for item in selected]

# 删选中项（从高行号删起，防索引偏移）
for row in sorted(rows, reverse=True):
    self._proj_file_list.takeItem(row)
```

### 1.4 加删除按钮的落点

`report_workbench.py:238-241`，紧挨"添加文件到资料列表"按钮旁:

```python
# line 238-241 — 现状: 只有添加按钮
add_proj_btn = QPushButton('添加文件到资料列表')
add_proj_btn.clicked.connect(self._on_add_project_file)
file_layout.addWidget(add_proj_btn)

# ↓ 加 HBoxLayout 并排: [添加] [删除选中]
# 或单加一个 remove_btn:
remove_btn = QPushButton('移除选中资料')
remove_btn.clicked.connect(self._on_remove_project_files)
# 还有 Keyboard Delete 键: self._proj_file_list.keyPressEvent 拦截
```

### 1.5 `get_config` 同步

`report_workbench.py:391-395`:

```python
def _get_project_file_paths(self) -> List[str]:
    return [
        self._proj_file_list.item(i).text()
        for i in range(self._proj_file_list.count())
    ]
```

**实时扫描 `_proj_file_list` 的所有 item。** `takeItem()` 删除后，列表长度自动减少 → `get_config()` 立即反映删除。无需手动同步。

## 2. 需求文件 (单文件) — `_req_file_path`

### 2.1 设值

`report_workbench.py:336-344`:

```python
def _on_select_req_file(self) -> None:
    path, _ = QFileDialog.getOpenFileName(self, '选择需求文件', '', 'Text Files (*.txt *.md);;All Files (*.*)')
    if path:
        self._req_file_path = path
        self._req_file_label.setText(f'需求文件: {path}')
```

### 2.2 是"选择"（设值）还是"切换/覆盖"

`QFileDialog.getOpenFileName` 用户可以重选新文件 → 覆盖旧值。可以 Cancel（不选）→ 保持旧值。
**但无法清除**——没有"清空需求文件"按钮。

### 2.3 加清除按钮的落点

`report_workbench.py:206-209`，"选择需求文件..."按钮旁:

```python
# line 206-209
req_btn = QPushButton('选择需求文件...')
req_btn.clicked.connect(self._on_select_req_file)
file_layout.addWidget(req_btn)

# ↓ 可改 HBoxLayout 并排: [选择需求文件] [✕ 清除]
clear_req_btn = QPushButton('✕')
clear_req_btn.clicked.connect(self._on_clear_req_file)

# _on_clear_req_file:
self._req_file_path = ''
self._req_file_label.setText('需求文件: 未选择')
```

### 2.4 `get_config` 同步

`get_config` 直接读 `self._req_file_path` (`line 130`)。清除后变为 `''` → 立即生效。

## 4. UI 布局结构

`_build_left_panel` 是完整的左侧面板构建方法 (`report_workbench.py:167-252`)。

### 4.1 当前控件排布

```
┌─ 报告生成工作台
├─ 报告类型 (Word/PPT radio)
├─ 资料选取
│   ├─ QLabel: "需求文件: ..."        ← _req_file_label
│   ├─ QPushButton: "选择需求文件..."  ← req_btn (line 206)
│   ├─ QLabel: "模板文件: ..."        ← _tmpl_file_label
│   ├─ QPushButton: "选择模板文件..."  ← tmpl_btn (line 217)
│   ├─ QLabel: "项目关联资料 (多选):"
│   ├─ QListWidget                   ← _proj_file_list (line 224)
│   └─ QPushButton: "添加文件..."     ← add_proj_btn (line 238)
└─ 操作
    ├─ "生成/预览报告大纲"
    ├─ "从已存诊断加载"
    ├─ "诊断数据: (...)"
    └─ "基于大纲生成完整报告"
    └─ "取消生成" (隐藏)
```

### 4.2 三个控件的布局容器都是 `file_layout` (QVBoxLayout)

删除按钮方案:

| 控件 | 按钮位置 | 改法 |
|------|---------|------|
| 需求文件 | `req_btn` 旁 | 包一层 `QHBoxLayout`: `[选择需求文件] [✕清除]` |
| 模板文件 | `tmpl_btn` 旁 | 同上: `[选择模板文件] [✕清除]` |
| 关联资料 | `add_proj_btn` 旁 | 包一层 `QHBoxLayout`: `[添加文件...] [移除选中]`；或依 Demand: 顶部加 `[删除选中]`、底部保持 `[添加]` |

**Keyboard Delete 键也可一并支持** — 重写 `_proj_file_list.keyPressEvent`（或安装 eventFilter），拦截 `Qt.Key.Key_Delete` → 调用 `_on_remove_project_files`。这比只加按钮更自然（用户选中后按 Del 即删）。

## 5. `get_config` 影响

`report_workbench.py:126-134`:

```python
def get_config(self) -> Dict[str, Any]:
    return {
        'req_file': self._req_file_path,            # ← 直接字段
        'template_file': self._template_file_path,   # ← 直接字段
        'project_files': self._get_project_file_paths(),  # ← 实时扫 QListWidget
    }
```

| 删除哪个 | `get_config` 是否自动同步 | 原因 |
|---------|------------------------|------|
| 关联资料项 | **是** — `_get_project_file_paths()` 实时扫列表 | `takeItem()` → 列表变短 |
| 需求文件 (`_req_file_path` = '') | **是** — 直接读 `self._req_file_path` | 设 `''` 即更新 |
| 模板文件 (`_template_file_path` = '') | **是** — 直接读 `self._template_file_path` | 设 `''` 即更新 |

**都不需要手动同步。** 但要注意：如果用户删光了关联资料，三入口的 `if not self._get_project_file_paths()` 硬拦会触发 → 阻止大纲/报告/加载。这是**正确行为**（关联资料空不应继续），需要在清除后提示用户"已移除所有关联资料，需重新添加才能继续"。
