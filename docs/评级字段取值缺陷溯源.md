# 评级字段取值缺陷溯源 — getattr(dict, …) 同类 bug（含修复后逻辑验证）

**日期**: 2026-06-25
**状态**: ✅ 已修复，待真机
**发现**: 快照输出 `评级=?(未通过)` 是对 dict 使用 `getattr` 的同类缺陷（与缺陷1 `getattr(dict, 'Ke1', 0)` 同源）

---

## §1 取值点确认 — getattr(dict, 'grade', '?') 恒返 ?

### 完整代码（修复前）

`core/data_providers.py:441-452` — `CalibrationProvider.get_summary()` 双栅分支结尾：

```python
                    grade = comp_d.get('grade')
                    if grade is not None and not isinstance(grade, (int, float, str)):
                        g = str(getattr(grade, 'grade', '?'))       # ← BUG
                        passed = bool(getattr(grade, 'passed', False))  # ← BUG
                        reasons = getattr(grade, 'reasons', []) or []   # ← BUG
                        if g in ('FAIL', 'ERROR'):
                            reason_str = '; '.join(str(r) for r in reasons[:2])
                            parts.append(f"评级={g}({reason_str})")
                        else:
                            parts.append(f"评级={g}" if passed else f"评级={g}(未通过)")
                    elif isinstance(grade, str):
                        parts.append(f"评级={grade}")
```

### 确认 grade 是 dict

**来源链**:

| 步骤 | 位置 | 值 |
|------|------|-----|
| ① `compensation` | `data_providers.py:299` | `pb.get('compensation', {})` — 从 `_phase_b_state` 取值，来自 JSON 持久化 |
| ② `comp_d` | `data_providers.py:417` | `compensation.get(s_name, {})` — `compensation` dict 的内层 dict |
| ③ `grade` | `data_providers.py:445` | `comp_d.get('grade')` — 取值自 `compensation[s_name]["grade"]` |

**grade 的实际形态** (来自 `SensorGrade.to_dict()` at `utils/compensation_metrics.py:151-158`)：

```python
# SensorGrade.to_dict() 返回:
{
    "sensor": "C2",
    "grade": "优",          # ← 真值在此，需 grade.get("grade")，不是 getattr
    "passed": True,
    "reasons": ["残余σ≤1%FS", "迟滞≤5%FS", "循环数≥3"],
    "is_single_grating": False,
}
```

**`grade` 是 `dict`，不是 `SensorGrade` 对象。** `getattr(dict, 'grade', '?')` 恒返 `'?'`。

### 与缺陷1同源确认

缺陷1：`getattr(dict, 'Ke1', 0)` — dict 无 `Ke1` 属性 → 恒返 0。
本次：`getattr(dict, 'grade', '?')` — dict 无 `grade` 属性 → 恒返 `'?'`。

**完全同源** — `compensation` 在 `_phase_b_state` 中始终是序列化后的 dict，不是活对象。

### 修复

三处全部从 `getattr(dict, key, default)` 改为 `dict.get(key, default)`，加 `isinstance(dict)` 守卫：
- 单栅评级: `data_providers.py:377-380`
- 补偿指标 metrics (8处): `data_providers.py:421-443`
- 评级 grade (3处): `data_providers.py:447-449`

## §2 "(未通过)" 后缀逻辑对账（修复后）

### 代码位置

`data_providers.py:451-455`：

```python
                        if g in ('FAIL', 'ERROR'):
                            reason_str = '; '.join(str(r) for r in reasons[:2])
                            parts.append(f"评级={g}({reason_str})")
                        else:
                            parts.append(f"评级={g}" if passed else f"评级={g}(未通过)")
```

### 修复前

`passed = bool(getattr(grade, 'grade', '?'))` — grade 是 dict，`getattr(dict, 'passed', False)` 恒返 `False` → **所有传感器都加 `(未通过)` 后缀**（包括 C2 优、A1 良）。

### 修复后

`passed = bool(_g.get('passed', False))` — 从 dict 真取值。

**按传感器走查**：

| 传感器 | grade["grade"] | grade["passed"] | 分支 | 输出 |
|--------|---------------|-----------------|------|------|
| C2 | `"优"` | `True` | else → passed=True | `评级=优` |
| A1 | `"良"` | `True` | else → passed=True | `评级=良` |
| A2 | `"FAIL"` | `False` | g in ('FAIL','ERROR') | `评级=FAIL(迟滞>5%FS)` |
| B1 | `"FAIL"` | `False` | g in ('FAIL','ERROR') | `评级=FAIL(迟滞>5%FS)` |
| B2 | `"FAIL"` | `False` | g in ('FAIL','ERROR') | `评级=FAIL(迟滞>5%FS)` |
| C1 | `"FAIL"` | `False` | g in ('FAIL','ERROR') | `评级=FAIL(迟滞>5%FS)` |

**`(未通过)` 不是"写死的硬扣"，是 `passed` 字段的条件后缀。修复后 `passed` 取真值 → "优"/"良"不加后缀、FAIL 走独立 reason 分支 → 后缀仅对 `passed=False` 且非 FAIL/ERROR 的边缘情况生效。逻辑自洽，不需额外修改。**

## §6 dec_d / decoupling 结构证据 — 确认无 getattr-on-dict bug

### 快照读取端

`data_providers.py:298,408-414`：

```python
decoupling = pb.get('decoupling_results', {}) or {}      # line 298
...
dec_d = decoupling.get(s_name, {})                        # line 355
...
if isinstance(dec_d, dict):
    e_std = dec_d.get('e_std', dec_d.get('e_range'))      # line 409
    if e_std is not None:
        parts.append(f"ε_std={float(e_std):.2f}με")      # line 411
    e_mean = dec_d.get('e_mean')                          # line 412
    if e_mean is not None:
        parts.append(f"ε_mean={float(e_mean):.2f}με")    # line 414
```

### 写入端 — 值的真实形态

`calibration_tab.py:2023-2038` — `PhaseBDialog._write_state_to_main_page()`：

```python
eps = np.asarray(r.get("eps_corr", np.empty(0)), dtype=np.float64)
e_mean = float(np.nanmean(eps)) if len(eps) > 0 else float("nan")    # → float 标量
e_std  = float(np.nanstd(eps)) if len(eps) > 0 else float("nan")     # → float 标量
e_range = float(np.nanmax(eps) - np.nanmin(eps)) if len(eps) > 0 else float("nan")  # → float 标量

decoupling[s_name] = {
    "e_mean": e_mean,     # float
    "e_std": e_std,       # float
    "e_range": e_range,   # float
    "rating": rating,     # str ("优"|"良"|"合格"|"差")
}
```

### 持久化路径

`calibration_tab.py:2062` → `project_config.py:450`：

```python
# calibration_tab.py:2062
"decoupling_results": decoupling,    # → tp._phase_b_state["decoupling_results"]

# project_config.py:450
"decoupling_results": dict(decoupling),  # → 项目文件 JSON
```

### 结论

**`dec_d` 所有值（e_mean / e_std / e_range / rating）均为标量（float 或 str），不是嵌套 dict。** 快照读取用 `dec_d.get('e_mean')` 是纯 `.get()` 对标量取值，不存在 `getattr(dict, ...)` 同类 bug。`[SNAP]` 显示 `ε_mean=21.24` 证实了这条链正确工作。
