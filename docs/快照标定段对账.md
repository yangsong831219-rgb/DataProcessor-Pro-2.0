## §1 Ke 真值是否进快照

### 数据源

Ke 值由 `PhaseBDialog._write_state_to_main_page()` 写入 `_phase_b_state["ke_table"]`：

| 步骤 | 文件:行号 | 说明 |
|------|-----------|------|
| 读取 UI 系数表 | `calibration_tab.py:1992-2000` | 遍历 `self.coef_table`，取第1列(Ke1)、第2列(Ke2) |
| 写入 ke_table | `calibration_tab.py:2000` | `ke_table[pfx] = {"Ke1": k1, "Ke2": k2}` |
| 持久化到状态 | `calibration_tab.py:2061` | `"ke_table": ke_table` → `tp._phase_b_state` |

**触发条件**: `_write_state_to_main_page` 仅在 Phase B 对话框 `accept()` 时调用（`calibration_tab.py:1984` 注释："仅 accept 调用"）。

### 快照读取

| 步骤 | 文件:行号 | 说明 |
|------|-----------|------|
| 读 phase_b_state | `data_providers.py:294` | `pb = getattr(tp, '_phase_b_state', {}) or {}` |
| 提取 ke_table | `data_providers.py:297` | `ke_table = _normalize_coeffs(pb.get('ke_table', {}))` |
| 格式化输出 | `data_providers.py:383-401` | 三级回退: ke_table 非零 → strain_ke 兜底 → `?/?` |

### 判定

- **若 Phase B 对话框已 accept**: ke_table 含 UI 表格中的真值（如 Ke1=1.18, Ke2=0.01）→ 快照输出 `Ke1/Ke2=1.1800/0.0100` ✅
- **若 Phase B 对话框未 accept**: `_phase_b_state` 为空或旧值 → ke_table 为空 → 回退到 `_get_strain_ke()` (读应变标定页 `_strain_configs`) → 若应变页也无 → 输出 `Ke1/Ke2=?/?` ❌

**关键时序**：`_on_done`（`calibration_tab.py:1826`）渲染结果表时，`_last_result` 已填充真值，但 **不写** `_phase_b_state`。诊断调用 `get_summary()` 读的是 `_phase_b_state`（persisted），不是对话框的 `_last_result`（live）。**若诊断触发于 Phase B 对话框 open 但未 accept 的窗口内，Ke 真值不出现在快照中。**

## §2 单/双栅描述来源

### 判定链路

| 步骤 | 文件:行号 | 逻辑 |
|------|-----------|------|
| 一级判定 | `data_providers.py:355-358` | `decoupling_results[s_name].get('single_grating') is True` → 单栅 |
| 二级判定 | `data_providers.py:360-361` | `dec_d.get('single_grating', True)` 默认 True；若显式 False → 双栅 |
| 三级判定 | `data_providers.py:362-363` | `s_name not in ke_table and dec_d` → 单栅（旧 profile 降级） |

### single_grating 字段的写入/缺失

| 位置 | 文件:行号 | 写入情况 |
|------|-----------|----------|
| PhaseBWorker.run() 传感器构造 | `calibration_tab.py:726,759` | ✅ 写入 `"single_grating": True/False` |
| 对话框 restore 重建 display_sensors | `calibration_tab.py:1618` | ✅ 从 `s_name not in ke_table` 推算 |
| **`_write_state_to_main_page` 写回 decoupling_results** | `calibration_tab.py:2035-2038` | ❌ **未写入** single_grating 字段 |
| project_config restore 写回 _phase_b_state | `project_config.py:448-452` | ❌ **未写入** single_grating 字段 |

**缺失点**: `decoupling_results` dict（`calibration_tab.py:2035-2038`）仅含 `e_mean / e_std / e_range / rating`，**不含 `single_grating`**。`get_summary` 依赖的 `decoupling_results` 永远读不到这个字段，必须走降级逻辑。

### Ke2≈0 双栅是否被误判为"单通道"

**代码层面**: Ke2≈0 的双栅传感器（如 A1: Ke1=1.18, Ke2=0.01）**不会被 `get_summary` 误判为单栅**，前提是 ke_table 已填充：
- `s_name in ke_table` → True → 三级判定 `s_name not in ke_table` → False → `is_single=False`

**模型层面风险**: 若 ke_table 为空（Phase B 未 accept），快照输出 `Ke1/Ke2=?/?`，模型可能从缺失的 Ke 值推断"此传感器无有效双栅系数"→ 自行判断为"单通道"。这是模型推断行为，不是代码判定。

### 漏项

| 字段 | 说明 |
|------|------|
| **原始 ε_mean 时序** | 不持久化。`_write_state_to_main_page:2024` 只存标量 `np.nanmean(eps_corr)` |
| **原始 ε_std 时序** | 同上，只存标量 |
| **双栅分离前的混合信号** | Phase B 不输出混合 ε，只在解耦后输出 `eps_corr` |
| **compensation.metrics 的详细残差分布** | 仅存 `residual_sigma_pct_fs` 标量，不存完整残差数组 |

### 判定

模型看到的 ε_mean/σ 有两种可能状态：
1. **dialog 已 accept**: `decoupling_results` 含 `e_mean=29.03, e_std=...` → 快照输出 `ε_mean=29.03με ε_std=X.XXμε` ✅
2. **dialog 未 accept**: `decoupling_results = {}` → `dec_d = {}` → `e_mean=None` → 不输出 ε_mean 行 → 模型看到标定段无 ε 指标 ❌

## §4 None 来源 — "未跑补" vs "漏"

### 场景分类

| 场景 | 触发条件 | decoupling_results | e_mean 状态 | 性质 |
|------|----------|-------------------|-------------|------|
| Phase B 未运行 | `_last_result = None` | `{}` (空) | 不输出 | **正常缺** — Phase B 确实没跑 |
| Phase B 已运行，dialog 未 accept | `_on_done` 已填充，`_write_state_to_main_page` 未调 | `{}` (空) | 不输出 | **时序漏洞** — 结果已算但未持久化到快照读取的状态源 |
| Phase B 已运行 + accept | `_write_state_to_main_page` 已调 | `{"A1": {"e_mean": 29.03, ...}}` | `29.03` | **正常** — 快照有值 |
| eps_corr 空数组 | 单栅或解耦异常 | `{"A1": {"e_mean": NaN, ...}}` | `NaN` → `e_mean is not None` 为 True → 输出 `ε_mean=nanμε` | **异常** — 快照输出 NaN 字符串 |

### 当前用户场景分析

用户报告 "B相表真值：A1/A2 是双栅、ε_mean/原始σ有值（C2 ε_mean=29.03）" → 说明 Phase B **已运行**（`_on_done` 渲染了结果表），但模型看到 ε_mean=None。

**根因推断**：诊断触发时，Phase B 对话框 **未 accept**。诊断读 `tp._phase_b_state`（对话框打开前的空状态），而非对话框内的 `_last_result`（已填充的真值）。

**关键证据链**：
- `get_summary` 读数据源：`tp._phase_b_state`（`data_providers.py:293-294`）
- `_phase_b_state` 写入点：仅 `_write_state_to_main_page`（`calibration_tab.py:2060`）和 `project_config.restore`（`project_config.py:448`）
- `_on_done`（`calibration_tab.py:1826`）只写 `self._last_result` + `self._compensation_results`，**不写** `tp._phase_b_state`

**不是"漏"（代码忘写字段），是"时序未同步"（快照读持久化状态，对话框结果尚未持久化）。**
