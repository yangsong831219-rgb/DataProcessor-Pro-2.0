## 二、要砍的旧路径

### 4. `_generate_charts_from_providers` 全文

`main.py:177-300`（`_generate_charts_from_providers` + `_gen_charts_for`）。

完整逻辑: 遍历 5 provider → 各 provider `is_available(main_win)` → 调 `_gen_charts_for`:

## 三、图仓 / manifest / 消费者改造点

### 6. `FigureManifest` + `save_figure`

**`FigureManifest`**: `core/report_charts.py:950-1000` — 类 `ReportFigure` (`report_charts.py:929`)。核心字段: `fig_id`/`fig_no`/`section`/`title`/`key_stat`/`png_path`/`caption`。方法: `add(fig_id, section, title, key_stat, png_path)` 递增 `fig_no`。`to_llm_context(max_chars)` 输出 LLM 可读的"图N: 标题 (key_stat)"文本。

**`save_figure`**: `report_charts.py:127-147` — 签名 `save_figure(fig, path, dpi=200)`。`fig.savefig(dpi, bbox_inches="tight")` → `plt.close(fig)` → `return path`。

**改造点**:

| 项目 | 改什么 | 在哪里 |
|------|--------|--------|
| 落盘目录 | `save_figure` 的 `path` 来自图仓: `{诊断记录目录}/charts/{记录ID}/{chart_id}.png` | chart_store.py (新建) |
| manifest 改受图仓 | `FigureManifest.add` 的 `png_path` 从图仓取 | chart_store.py → manifest |
| dpi 可配 | 保持 200 默认，图仓可 override | chart_store |

## 四、行为等价验证可行性

### 10. 逐图一致验证

**不存在图像对比测试基建**。当前测试只验证 `manifest` 的 `fig_id` 是否存在、PNG 文件大小 > 200 bytes（`test_chart_bundle_from_providers.py:404-406`）。

**PNG 不稳定因素**: matplotlib 的字体渲染 (SimHei/Microsoft YaHei)、bbox_inches="tight" 在不同环境/字体安装下产生不同像素。**不能做逐字节 MD5 对比。**

**建议验收手段**:
1. **结构验证** (可自动化): 新旧路径 `manifest` 的 `fig_id` 集合相同 (`assert set(old_ids) == set(new_ids)`)
2. **尺寸验证** (可自动化): 新旧 PNG 的 `Image.open` 后 `size`(宽高) 相近（相同 dpi 下应精确相等）
3. **真机肉眼** (不可自动化): 并排对比两张同名 PNG，确认肉眼不可辨
4. **Word/PPT 注图位置不变**: 验证 `manifest.to_llm_context()` 输出的图序、图号、caption 完全一致
