## 1. 快照构建入口

### 1.1 `data_source_snapshot` 生成者

诊断记录中的 `rec["data_source_snapshot"]` 由 `_get_enabled_provider_summaries()` 生成：

```python

```

```python
# ui/ai_diagnosis.py:1560-1581
def _get_enabled_provider_summaries(self, main_win: Any) -> list[str]:
    """遍历勾选且可用的 provider，收集其 get_summary() 文本。"""
    from core.data_providers import get_all_providers
    summaries: list[str] = []
    providers = get_all_providers()
    for p in providers:
        entry = self._source_checkboxes.get(p.display_name)
        cb = entry[0] if entry else None
        if cb is None or not cb.isChecked():    # ★ 未勾选 → 跳过
            continue
        available = p.is_available(main_win)
        if available:
            try:
                s = p.get_summary(main_win, budget_chars=2000)
                if s.strip():
                    summaries.append(s)
            except Exception:
                summaries.append(f"【{p.display_name}】读取失败")
        else:
            summaries.append(f"【{p.display_name}】未运行/无最新结果")
    return summaries
```

**两道门控**:
1. 用户在 AI 诊断面板的「数据源」区域是否**勾选了该 provider** (`cb.isChecked()`)
2. 该 provider 的 `is_available()` 是否为 `True`

> 如果「传感器标定」复选框未被勾选，CalibrationProvider 的摘要文本根本不会进入快照。

## 2. 标定段内容 — CalibrationProvider.get_summary() 注入文本

### 2.1 完整摘要方法

`core/data_providers.py:282-427` — CalibrationProvider.get_summary()

### 2.2 输出格式示例

```
【传感器标定】（传感器标识: A1=FBG_A1, A2=FBG_A2, ...）
  A1: KT=26.1000 | Ke1/Ke2=1.18/? | ε_std=2.50με | ε_mean=1.20με | FS=1000με | 补偿后σ=0.850%FS(LOOCV) | 迟滞=1.200%FS | 评级=优
  A2: KT=28.5000 | Ke1/Ke2=?/? | 单栅 | 评级=N/A (单栅不解耦)
```

### 2.3 文本内容随数据可用性变化的三种路径

| 路径 | has_a | has_b | 输出 |
|------|-------|-------|------|
| A | False | False | `(未运行)` — `data_providers.py:301` |
| B | True | False | 列出传感器但 Ke/解耦数据全为 `?` — 因为 `sensor_ids` 来自 `ke_table` + `decoupling` 空的 keys → 空集合 → `(无传感器数据)` — `data_providers.py:322-324` |
| C | True | True | 完整 Ke/解耦/评级文本 |

**路径 B 是关键缺陷**: S_eff 存在（has_a=True），但 ke_table 为空且 decoupling 为空时，输出是 `(无传感器数据)` 而非 S_eff 的文本。S_eff 的数值（温度灵敏度、基准温度）白白丢失。

## 3. 计数口径 — is_available() 判定标定是否"有数据"

### 3.1 判定逻辑

```python
# core/data_providers.py:265-273
def is_available(self, main_win: Any) -> bool:
    tp = self._get_temp_page(main_win)
    if tp is None:
        return False
    pa = getattr(tp, '_phase_a_state', {}) or {}
    pb = getattr(tp, '_phase_b_state', {}) or {}
    has_a = bool(pa.get('seff_result'))
    has_b = bool(pb.get('decoupling_results') or pb.get('compensation'))
    return has_a or has_b
```

**判断依据**: Phase A 的 `seff_result` 是否非空 **或** Phase B 的 `decoupling`/`compensation` 是否存在。

### 3.2 ke_table 不参与 is_available 判定

**`ke_table` 不作为 is_available 的判据**。如果用户只填写了 Ke 系数但未运行 Phase B（无 decoupling/compensation）且 Phase A 的 `seff_result` 因某种原因为空（如 S_eff 数据未写入 `_phase_a_state`），`is_available()` 返回 `False` → CalibrationProvider 摘要被跳过 → Ke 值根本不进入快照。

### 3.3 Phase A 写入 `_phase_a_state["seff_result"]` 的触发条件

```python
# ui/calibration_tab.py:1492-1501
def _write_state_to_main_page(self):
    tp = self._get_temp_page()
    if tp:
        tp._annotation_dict = dict(self._annotation)
        ...
        if self._phase_a_result:              # ★ 仅当 Phase A 结果存在时
            tp._last_result = self._phase_a_result
            tp._phase_a_done = True
        tp._phase_a_state = {
            ...
            "seff_result": self._phase_a_result,  # ★ 可能为 None
        }
```

**即使 `_phase_a_result` 为 `None`，`_phase_a_state["seff_result"]` 也会被设为 `None`**。`bool(None)` = `False` → `has_a` = `False`。

此方法仅在对话框 `accept()`（用户点"确定"）时调用：
```python
# ui/calibration_tab.py:1508
def accept(self):
    self._write_state_to_main_page()
```

## 4. Ke 数值是否到达模型 — 两条路径

### 4.1 路径 1：CalibrationProvider → 温度页 ke_table

```python
# core/data_providers.py:358-370 — 优先从应变页取精值，回退到温度页 ke_table
strain_ke = _get_strain_ke(main_win, s_name) if main_win else None
if strain_ke:
    ke1_s = f"{float(strain_ke['Ke1']):.4f}"
    ke2_s = f"{float(strain_ke['Ke2']):.4f}"
else:

    if isinstance(ke, dict):
```

### 4.3 Ke 到达模型的四个门控条件

| # | 门控 | 位置 | 若不满足 |
|---|------|------|---------|
| 1 | 「传感器标定」复选框已勾选 | `ui/ai_diagnosis.py:1568` | CalibrationProvider 摘要不注入 |
| 2 | `is_available()` 返回 True | `core/data_providers.py:273` | 摘要为"未运行" |
| 3 | `sensor_ids` 非空（ke_table 或 decoupling 有键） | `core/data_providers.py:306-312` | 输出"(无传感器数据)" |
| 4 | Ke1/Ke2 在 ke_table 或 _strain_configs 中有实际值 | `core/data_providers.py:359-369` | 输出 `Ke1/Ke2=?/？` |

**如果 ke_table 中 Ke1 未写入但应变标定已完成**: `_get_strain_ke` 查 `sp._phase_b_state` → 此属性在 StrainCalibrationPage 上**不存在**（真属性是 `_ke_results` 在 `StrainCalibrationPage` 直接实例变量）→ `_get_strain_ke` 返回 `None` → 回落 ke_table → 输出 `?`。
